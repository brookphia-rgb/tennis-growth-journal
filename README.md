# 许子越网球成长记录

面向手机使用的个人训练日志 PWA，覆盖网球训练、体能训练、比赛复盘、拉伸恢复、饮食与休息。

线上地址：`https://brookphia-rgb.github.io/tennis-growth-journal/`

## 当前功能

- 自然语言一次识别多条训练、恢复和日常记录
- 五类结构化记录表单
- 历史记录查看、筛选、编辑和删除
- 每周训练统计、不足提醒和下周建议
- 自定义账号密码登录
- 手机与电脑之间的云端自动同步
- 断网本地记录、联网自动补传
- JSON 备份导入和导出
- PWA 安装结构和 Service Worker 离线缓存

## 数据和同步

记录保存时先写入浏览器 `localStorage`，登录状态下约 500 毫秒后自动同步到 Supabase。

登录时会下载云端数据并与本机数据合并：

- 不同记录全部保留。
- 同一条记录以更新时间较新的版本为准。
- 离线删除会在恢复联网后补删。
- 训练目标等设置也会同步。

数据库启用了 Row Level Security。每个账号只能访问自己的数据。网页中的 Supabase `anon` key 是浏览器端公开密钥，数据权限由登录身份和 RLS 控制。

## 账号登录

首次使用时，在设置页输入自定义账号和至少 6 位密码，然后点击“首次创建账号”。其他设备使用相同账号和密码点击“登录”。

密码由 Supabase Auth 处理，项目代码不会保存明文密码。不要把正式密码写入代码、日志或问题记录。

## 本地运行

项目没有构建依赖，使用任意静态服务器即可：

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173`。

## 技术结构

- 前端：原生 HTML、CSS、JavaScript
- 云端数据库和登录：Supabase
- 部署：GitHub Pages
- 离线缓存：Service Worker + `localStorage`
- Supabase 浏览器脚本：项目内 `supabase.js`
